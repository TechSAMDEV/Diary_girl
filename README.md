# 📖 Diary Girl

> A modern, secure, and intuitive digital diary web application designed for personal reflection, daily logging, and capturing thoughts on the go.

🌐 **Live URL:** [https://diary-girl.vercel.app/](https://diary-girl.vercel.app/)

---

## ✨ Features

* **Secure Authentication:** User accounts to keep personal entries private and protected.
* **Rich Entry Creation:** Create, edit, and delete daily diary entries effortlessly.
* **Responsive Design:** Optimized for seamless usage across mobile devices, tablets, and desktops.
* **Clean & Minimalist UI:** Designed for a calming, distraction-free journaling experience.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Styling:** Bootstrap / Custom CSS
* **Deployment:** Vercel
